Mafore Notepad 1.0.1
====================

Автоматическая сборка Windows EXE выполняется через GitHub Actions.
После успешной сборки откройте вкладку Actions в репозитории, выберите
последний запуск "Build Mafore Notepad for Windows" и скачайте артефакт
MaforeNotepad-Windows. Внутри находится MaforeNotepad.exe.

Для запуска готового EXE Python на компьютере пользователя не требуется.
